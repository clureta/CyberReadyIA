# CyberReadyIA
CyberReady AI es una plataforma en fase de prototipado que explora el uso de IA agéntica y Regulatory Chaos Engineering para simular ciberincidentes, identificar dependencias críticas y evaluar si una organización podría ejecutar realmente su respuesta antes de enfrentar una crisis real. Nace en Chile con visión de escalabilidad hacia LA.
