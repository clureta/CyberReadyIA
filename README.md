# CyberReady AI - Demo simulada para validación del PMV

Esta versión NO representa un producto terminado ni una evaluación real de cumplimiento. Está diseñada para entrevistas y sesiones de validación con CISOs, DPOs, equipos de riesgo, SOC, proveedores y expertos de IA.

## Cómo abrir
### Windows
Doble clic en `ABRIR_DEMO_WINDOWS.bat` o directamente en `index.html`.
### macOS
Doble clic en `ABRIR_DEMO_MAC.command` o abrir `index.html` en el navegador.

No requiere Node.js, Python, servidor, API, base de datos, claves ni internet.

## Qué demuestra
1. Hipótesis de problema.
2. Decision Twin conceptual.
3. Tres escenarios simulados.
4. Orquestación visual de cinco agentes conceptuales.
5. Hallazgos explicables y Human-in-the-Loop.
6. Regulatory Chaos Mode con scoring determinista.
7. Hipótesis de valor y modelo B2B.
8. Formulario de validación y descarga de notas.

## Qué NO hace
- No analiza infraestructura real.
- No se conecta a SIEM/EDR/CMDB.
- No determina cumplimiento legal.
- No envía reportes a autoridades.
- No usa LLM real en esta versión.
- No procesa datos empresariales reales.

## Flujo recomendado de demo
1. Contexto: “Los planes existen; queremos saber dónde fallan antes de una crisis.”
2. Decision Twin: explicar las dependencias mínimas.
3. Simular “Ransomware en CRM”.
4. Abrir 1–2 hallazgos.
5. Ir a Chaos Mode y activar “Proveedor crítico no responde”.
6. Mostrar caída del readiness.
7. Ir a “Validar hipótesis” y pedir feedback al experto.

Todos los nombres, contratos, SLAs, scores y hallazgos son ficticios.
