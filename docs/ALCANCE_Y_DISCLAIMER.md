# Alcance de la demo

CyberReady AI se encuentra en fase de ideación y definición del MVP. Esta demo utiliza escenarios, organizaciones, datos, documentos, tiempos, scoring y hallazgos ficticios para facilitar conversaciones con potenciales usuarios y expertos.

Los módulos denominados “Agent” representan responsabilidades futuras. En esta versión, la secuencia y resultados se ejecutan localmente mediante reglas y datos premodelados.

La demo no presta asesoría jurídica, no certifica cumplimiento, no clasifica incidentes reales y no debe utilizarse para tomar decisiones operacionales durante una crisis.
