# Human-in-the-Loop (HITL) — Demo simulada

## Objetivo
Demostrar que CyberReady AI automatiza el análisis y la recomendación, pero no delega decisiones críticas a la IA.

## Flujo
1. Ejecutar un escenario.
2. Revisar hallazgos.
3. En Chaos Mode activar una falla, por ejemplo **Proveedor crítico no responde**.
4. Abrir **Human Review**.
5. La recomendación queda en estado `PENDING_HUMAN_REVIEW`.
6. El usuario puede **Aprobar**, **Modificar** o **Rechazar**.
7. La decisión se registra en un **Audit Trail** demostrativo.

## Mensaje para la demo
> “CyberReady automatiza el análisis, no la responsabilidad. La IA propone; el CISO decide.”

## Importante
Esta sección es conceptual. No ejecuta acciones reales ni se conecta con sistemas empresariales. Sirve para validar con usuarios si este modelo de control, aprobación y trazabilidad debería formar parte del MVP.
